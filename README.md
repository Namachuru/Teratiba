Teratiba

Teratiba is an operating system designed to help old computers work with new ones.

---

Features
- Fast loading due to minimal use of system resources  
- Simple and user-friendly interface
- Word Processing, Spreadsheet, Powerpoint Software package  
- Music Player Video Player
- Accessories such as calculator, notepad, paint, remote desktop, disk defragmentor
- Several Games
- Learn Kiswahili and Nugae Language by simply using the system.

---

Tech Stack
- Java

Problem It Solves
- Many drivers face challenges in tracking fuel expenses and accessing consistent discounts. Fuel Fasta addresses this by digitizing fuel transactions and enabling drivers to benefit from structured discount systems, improving cost efficiency and operational sustainability.
